# COLLEGE Course Enrollment Management System
## SAP ABAP RAP Project — Exercises 01 to 10

---

## Project Overview
Course Enrollment Management System for Centurion University
built using SAP ABAP RESTful Application Programming (RAP)
with Fiori Elements UI.

---

## Technical Stack
- Platform  : SAP BTP ABAP Environment
- Framework : ABAP RAP Managed Scenario
- UI        : SAP Fiori Elements (List Report + Object Page)
- Protocol  : OData V4
- IDE       : Eclipse ADT
